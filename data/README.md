# Data

| Path | What it is |
|---|---|
| `counts/` | per-barcode read counts, one CSV per sorted sample — the output of `pipeline/` and the entry point for all analysis |
| `qc/` | barcode-matching QC per sample: match rates, read fate, mismatch-tolerance comparison, top unmatched sequences |
| `processed/` | seven files the figures read: six regenerated by `run_all.sh`, one hand-curated |
| `library/` | the GPCRome library annotation table, one row per barcoded construct |
| `external/` | third-party reference data — see `external/README.md` |
| `inhouse/` | a legacy coupling annotation from an earlier screen, used only as a fallback in `build_coupling.py` |

## Samples

Two replicate sorts, four bins each: 20260924 (s5–s8) and 20260926 (s9–s12).

| Day | Samples | Role |
|---|---|---|
| 20260924 | s5–s8 | replicate 1 |
| 20260926 | s9–s12 | replicate 2 |

Bins are `a`–`d` in order of increasing CRE–eGFP reporter fluorescence.

## Column reference

**`Barcode` is the unit of analysis throughout.** One barcode = one construct. `isoform` is
`canonical` or `alt_isoform`, and the two are never collapsed to the gene — 3 genes (GRM8,
RXFP1, RXFP2) carry two canonical barcodes each, so the 727 canonical barcodes cover 724
distinct receptors and `rank` is a rank over barcodes, not receptors.

**`BarcodeID` is a UniProt accession, not a barcode identifier.** It is named that way in
the original reference tables and the name is kept for continuity.

### `processed/basal_scores_per_barcode.csv` — one row per construct

| Column | Meaning |
|---|---|
| `symbol`, `transcript_id`, `Barcode`, `BarcodeID` | HGNC symbol, Ensembl transcript, 10 bp barcode, UniProt accession |
| `<day>_a` … `<day>_d` | raw read counts in each sorted bin on that day |
| `<day>_reads` | those four summed; a day counts for a barcode only at ≥ 50 |
| `<day>_wmb_raw14` | weighted mean bin on the raw **1–4** scale |
| `<day>_wmb` | the same value rescaled to **0–1** — note the naming trap |
| `<day>_wmb_rawcounts` | WMB weighted by raw counts instead of within-bin frequencies |
| `score` | **the basal cAMP index**: mean of the two days, 0–1 |
| `score_sd` | SD between the two days, 0–1 |
| `score_rawcounts` | `score` under raw-count weighting (agrees at r = 0.9995) |
| `n_days` | how many days passed the read threshold; all analysis uses `n_days == 2` |
| `total_reads` | reads over all eight bin libraries — the library-abundance measure |

### `processed/coupling_annotation.csv` — coupling, from IUPHAR/GtoPdb

| Column | Meaning |
|---|---|
| `coupling_display` | the figure label: `Gs only`, `Gs + other`, `Gs secondary`, `Gq`, `Gi`, `multi (no Gs)`, `Golf`, `gustducin`, `unassigned` |
| `gs_primary` | Gs is among the primary transducers |
| `gs_any` | Gs is a primary **or** secondary transducer. **Always state which of these two an AUC refers to** |
| `couples_gs/gi/gq/g12` | one independent boolean per transducer family, primary tier |
| `gs_secondary` | Gs appears in the secondary tier |
| `n_primary_families` | how many primary families are listed (no rank is given among them) |
| `gtopdb_primary`, `gtopdb_secondary` | the raw GtoPdb strings |
| `coupling_source` | which source resolved this receptor |
| `legacy` | the superseded hand annotation, kept for comparison |
| `tedman_class` | structural class (A/B/C/F, olfactory, taste, vomeronasal) |
| `transducer`, `coupling_family` | single-label back-compat columns; prefer the booleans |

### `processed/canonical_scores_ranked.csv` — the 727 canonical barcodes, ranked

`rank` (1 = highest basal score), `score`, `score_sd`, `total_reads`, `coupling`,
`low_depth` (`total_reads < 1000`), plus the hand curation: `ca_evidence`
(`established` / `reported` / `weak` / `none found` / `not assessed` / `not reviewed`),
`ca_mechanism`, `ca_caveat`, `ca_source`. **Only the top 40 were reviewed** — `not reviewed`
means nobody looked, not that no evidence exists.

### `processed/receptor_construct_features.csv` — construct-level annotation

`gpcr_class` (A/B/C/F/Taste/Vomeronasal), `ligand_family` (prefix-matched from the gene
symbol, class A only; `n/a (non-class-A)` otherwise), `is_orphan`, `num_tmds`,
`signal_peptide` (TOPCONS call), `gly_fix` (whether a glycosylation-site fix was applied
in construct design), `orf_len` (gene-block length in **nucleotides**).

### `processed/basal_vs_tedman_pme.csv` — joined to published surface expression

`tedman_pme` / `tedman_pme_sd` / `tedman_log10_pme` are immunostaining intensity in
arbitrary units; `pme_compressed` flags values ≥ 4000, where the source estimate saturates.
For alternative isoforms, `canonical_pme` is their own canonical's value, `pct_change_pme`
the difference, `canonical_basal` the canonical's basal score, `d_basal` isoform minus
canonical. `ambiguous_construct` flags the two transcripts (GRM8 ENST00000358373,
RXFP2 ENST00000380314) that appear twice in the source with very different values and
cannot be paired to a barcode.

> **Encoding wart:** in this one file `olfactory` and `ambiguous_construct` are written as
> `1.0`/`0.0`/blank while `pme_compressed` and `canonical_pme_compressed` are `True`/`False`.
> Filtering `olfactory == True` returns nothing; use `olfactory == 1`.

### `processed/literature_constitutive_activity.csv` — a hand-curated **input**

40 rows, the top 40 canonical receptors only. Nothing regenerates this file; it is the
source of the `ca_*` columns above. Do not delete it when clearing `data/processed/`.

`ca_source` cites the supporting literature informally — mostly PMC accessions
(resolvable at `https://www.ncbi.nlm.nih.gov/pmc/articles/<PMCID>/`), occasionally a
journal and year or a PDB entry. 30 of the 40 rows carry a source; the 10 blanks are the
receptors graded `not assessed`, where no constitutive-activity study was found.

### `qc/read_fate.csv` — the input to Supplemental Figure 1b

One row per retained sample: `raw` (read pairs off the sequencer), `trimmed` (surviving the
primer-anchored cut), `library` (matched to a reference barcode), `contaminant` (the
off-library barcode and its 1-mismatch family), `other_unmatched` (the remainder).
`qc/qc_summary.csv` holds the per-sample match rates quoted in `../docs/SEQUENCING_QC.md`.
